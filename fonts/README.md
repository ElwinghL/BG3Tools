# MesloLGS NF

Police utilisée par le TUI pour son icône Nerd Font (bouton "internet").
Fichiers redistribués tels quels depuis la distribution officielle du
projet [Nerd Fonts](https://github.com/ryanoasis/nerd-fonts) / liée par
[Powerlevel10k](https://github.com/romkatv/powerlevel10k#fonts), qui les
fournit en téléchargement direct pour cet usage exact (configurer la
police d'un terminal). Voir `bg3_mod_tui/terminal_launcher.py` : ces
fichiers sont installés automatiquement pour l'utilisateur courant au
premier lancement du TUI (pas besoin de les installer à la main).
